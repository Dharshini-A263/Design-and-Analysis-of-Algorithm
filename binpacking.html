💡 Approximation Techniques

First Fit (FF): Put each item in the first bin where it fits.

First Fit Decreasing (FFD): Sort items from largest to smallest, then apply First Fit.

Best Fit (BF): Put an item into the bin that leaves the smallest remaining space.

Best Fit Decreasing (BFD): Sort decreasingly, then apply Best Fit.

📊 Complexity

First Fit: O(n²) in this implementation
Best Fit: O(n²) in this implementation
FFD: O(n log n + n²)
BFD: O(n log n + n²)
